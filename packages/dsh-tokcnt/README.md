# dsh-tokcnt

Show input/output/cache token usage per message in the DSH web UI.

## Install

Install via the [awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) list, or from this monorepo subdirectory (`packages/dsh-tokcnt`).
