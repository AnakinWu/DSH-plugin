# dsh-dsweb

One-click button to open the DeepSeek web chat (https://chat.deepseek.com) from the DSH sidebar.

## Install

Install via the [awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) list, or from this monorepo subdirectory (`packages/dsh-dsweb`).
