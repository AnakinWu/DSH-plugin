# Changelog

## 1.4.0
- Archive age is now based on the last human message (>= 3 days) instead of log mtime.

## 1.3.0
- Auto-archive idle sessions (3-day threshold, configurable).
- Search in the restore panel.
- True session titles recovered from logs.
- One-click archive button.

## 1.1.0
- Blank-session detection hardened (line-by-line parse, conservative skip).
- Restore grace window to protect recently found sessions.

## 1.0.0
- Initial release: restore panel for archived sessions.
